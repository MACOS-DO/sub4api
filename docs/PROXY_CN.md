# 代理配置：每个账号一个独立 IP

Claude、Codex、ChatGPT 账号会按登录 IP 做风控。多个账号共用一个出口 IP，或者 IP 来自机房，一个账号被封往往会连带其他账号。最稳的做法是：**一个账号绑定一个固定的家宽 / ISP IP，之后不再更换。**

Sub4API 支持给每个账号单独设置代理，下面是完整步骤。

## 1. 准备 IP

每个账号准备一个静态 IP，要求：

- **固定不变**：同一个账号一直用同一个 IP，不要用轮换代理。
- **家宽或运营商 IP**：机房 IP（IDC）更容易触发验证和封号。
- **地区与账号一致**：注册在美国的账号用美国 IP，日本账号用日本 IP。
- **每个 IP 只给一个账号**：不要多账号共用。

推荐 [ProxyLane 静态 ISP](https://proxylane.dev/go/macosdo-docs)：美国 Comcast / RCN / Verizon 家宽，日本、新加坡原生 IP，20+ 国家可选；同一账户下购买的 IP 自动分到不同网段。支持 PayPal、USDT 付款，ISP 首单使用优惠码 `MACOSDO20` 享 8 折。

## 2. 导出代理列表

在 ProxyLane 后台「ISP 代理」中选中要用的 IP，复制格式选 `protocol://user:pass@ip:port`，每行一个：

```
socks5://user:pass@203.0.113.10:30617
socks5://user:pass@203.0.113.11:30618
```

如果希望 DNS 也走代理，可以把前缀改成 `socks5h://`（Sub4API 支持 SOCKS5H 远程 DNS）。

## 3. 导入 Sub4API

1. 打开「IP管理」，点击「快捷添加」。
2. 把上一步的列表粘贴进「代理列表」，每行一个，确认导入。重复的代理会自动跳过。
3. 导入后可以用「批量测试」或「批量质量检测」确认每个 IP 都能连通。

## 4. 给每个账号绑定一个 IP

1. 打开账号管理，编辑账号，在「代理」中选择一个刚导入的 IP。
2. 每个账号选不同的 IP。在「IP管理」里点开某个代理，可以在「使用该IP的账号」中确认它只绑定了一个账号。
3. OpenAI 账号的「请求时区」建议选「跟随 IP 出口」：保存后会自动按出口 IP 所在地设置时区，让请求环境和 IP 一致。

## 5. 日常注意

- 不要频繁给同一个账号换 IP；确实需要更换时，换成同地区的另一个固定 IP。
- 登录、授权（OAuth）时，浏览器也要走这个账号绑定的同一个 IP。
- IP 到期前记得续费，续费后 IP 不变，账号无需重新绑定。
