# v1.1.11

## 更新内容

- Codex 打票改为全站共享一张票：任一账号打出后，所有参与打票的账号在所有门控模型上共用。
- 票据失效改为按账号生效：某账号请求返回的 turn-state 与 `__oailb` 同时变化时，只有该账号停用这一代票，其他账号继续使用，并立即重新打票。
- 打票改为分批并发进行，可在打票节奏设置中调整每批账号数。
- 打票参与改为账号级开关，不再按模型单独设置。
- IP 管理页的打票代理池设置收进“打票代理池”按钮，在弹窗中选择代理。
- 优化票据中心、打票节奏设置等界面样式。

## 升级说明

- 升级时会把各账号已有票据中最新的一张迁移为共享票，并清除原有的按账号票据和按模型的参与设置。
- 启用缺票拦截时，账号在自己这一代票失效、新票打出前会暂停调度。
