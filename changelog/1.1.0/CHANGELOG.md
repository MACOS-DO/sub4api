# v1.1.0

## 新增功能

- 新增账号列表独立打票状态列和打票详情，支持查看各模型票据的有效状态、到期时间及最近成功记录，手动重新打票，并按账号、模型控制是否参与打票。
- 新增打票请求流水和成功记录，支持分页查看自动、手动打票的结果、时间、HTTP 状态、票据长度、耗时、代理和失败原因。成功记录持续保存，未命中及失败记录保留最近 30 天。
- 新增打票代理池，可选择全部可用代理或指定代理，轮换使用已启用且未过期的代理；全部模式会自动包含后续新增的可用代理。

## 优化改进

- 统一票据获取、缓存读取和请求转发的校验规则，兼容 Team 账号的 332 长度票据，并支持接收 HTTP 429 响应中符合校验规则的有效票据。
- 自动打票依据账号已有的限流重置时间暂停，并在重置前 30 分钟恢复；打票详情同步展示暂停状态和预计恢复时间。
- 优化自动重试节奏：取得有效票据后延后首次重试，根据是否仍持有有效票据调整后续重试间隔；增加同一账号、模型的跨实例互斥，避免自动与手动打票重复并发。

## 问题修复

- 修复 Docker 容器内在线更新因 `/app` 目录不可写而无法创建临时目录的问题，使普通运行用户具备在程序目录创建临时文件、备份、原子替换及回滚所需的权限。

## 升级说明

- 打票代理配置入口调整为「代理管理」中的「292 打票代理池」。原独立打票代理地址不会自动导入代理池，请在代理管理中添加或确认原代理，并按需选择参与打票的代理。代理池默认使用全部可用代理；没有可用代理时无法打票。
- 新版首次启动时会自动执行打票历史表的数据库迁移，创建请求流水及历史记录所需的存储。
- 现有 Docker 部署请拉取 `1.1.0` 镜像并重新创建 `sub4api` 服务，同时保留现有数据卷；仅下载新版二进制不会修复旧镜像的目录权限。
