# v1.1.5

## 更新内容

- 新增独立的 OpenAI BPS 平台，通过 ChatGPT Excel/BPS 上游提供 HTTP Responses 服务。支持手动配置 Access Token、ChatGPT Account ID、代理、账号分组、模型映射与连接测试，默认候选模型为 `gpt-6-astra`、`gpt-5.6-sol`。
- BPS 账号自动提取 JWT 中的账号标识和到期时间，支持手动覆盖账号 ID；凭证脱敏展示，编辑留空保留原 Token，替换凭证不会解除管理员主动停用状态。
- 接入现有调度、用量日志、计费、用户平台配额和渠道监测。BPS 分组只使用 BPS 账号；Composite 分组通过显式路由选择 BPS，普通 `gpt-*` 自动识别规则保持原有行为。
- 增加 Codex 工具协议转换：将 function、custom、namespace 和 additional_tools 声明转换为文本目录，经原生 `run_officejs` 承载工具请求，再恢复客户端工具调用。支持信封别名、嵌套 JSON、custom 原始文本及 update_plan 参数和回执适配，工具仍由客户端执行。
- 通过 Redis 保存完整原始工具调用、账号绑定和压缩摘要，支持跨实例续接与 7 天闲置过期。规范化工具结果 ID 和加密 reasoning 回放，已建立上下文的会话不会自动换号重放。
- 支持 `/responses/compact` 和 Responses 压缩请求，使用真实文本摘要及不透明引用恢复上下文。压缩前后保持用户轮次，工具结果仅递增迭代次数，兼容旧摘要记录和连续压缩。
- 支持 `text.format` 的 JSON Object / JSON Schema 输出，通过提示词约束与本地最终结果校验保证输出格式，保留大整数精度。结构化文本在校验通过后才发送；工具调用、明确拒答和压缩分别处理，校验失败保留实际用量并返回明确错误。
- 完善 JSON/SSE 转换：普通文本实时输出，工具在完整解析、验证和保存后交付；异常断流或终态丢失工具 item 时返回失败，不伪造成功完成事件。
- 修复 Composite 模型目录遗漏 BPS 别名、无有效候选时错误回退全部平台模型，以及 BPS 标准模型列表格式不兼容的问题。
- 正确识别 BPS 模型权限错误，按实际映射模型冷却 30 分钟，不停用账号的其他模型；Token 过期或认证失败停止该账号调度，429 沿用上游退避信息。


- 完善 BPS 凭证状态提示，区分 Token 自然过期、上游撤销和认证失败。状态栏、用量列与编辑窗口统一显示原因，自然过期提示每 30 秒更新，测试结束后自动刷新账号状态。
- BPS 认证失败按本次请求的 AT 与账号 ID 条件写入，防止迟到响应影响新凭证；保留管理员停用和手动暂停设置，凭证更换不会误开启账号。
- 新建 BPS 账号增加醒目的账号限制/封禁风险警告；保存与保存并测试均需再次确认，取消不创建账号并保留输入。
- BPS 连接测试仅在收到真实响应后显示 HTTP 状态，并保留错误码、上游模型和请求 ID，避免提前显示“已连接”造成误解。

## 升级说明

- 运行版本号为 `1.1.5`，本次候选镜像标签为 `macosdo/sub4api:1.1.5-rc`。
- 启动时需完成 `245_openai_bps_platform.sql`，扩展平台约束；不新增账号凭证表。Redis 为 BPS 必需依赖。
- BPS Token 需要手动替换，不提供自动续期。首版支持 HTTP Responses、文本输入与串行工具，不提供 WebSocket、Chat Completions、图像或音频接口。
- 结构化输出采用提示词约束加本地校验，不是上游原生约束解码。无效 schema 返回 400，不符合输出格式的最终响应返回 502 或 SSE 失败事件。
- BPS 使用需要完整历史；状态过期或绑定账号不可用时需恢复该账号或新建会话。正式使用前，请在测试分组验证实际账号权限，以及 Codex 工具、压缩和结构化输出链路。
- 配置与协议来源说明见 `docs/openai-bps.md` 和 `docs/openai-bps-sources.md`。
