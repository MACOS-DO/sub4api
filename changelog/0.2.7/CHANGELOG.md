# v0.2.7

项目迁移至 Sub4API，统一仓库与发布来源，并保留原有部署配置的兼容入口。

## 新增功能

- main 提交自动构建并发布 GHCR、Docker Hub 双架构镜像。
- 发布 Linux、macOS、Windows 安装包和 SHA-256 校验文件。
- 按版本目录维护中文 Release 更新说明。

## 优化改进

- 项目名称、Go 模块、安装文档和在线更新来源统一迁移至 MACOS-DO/sub4api。
- 支持原有环境变量、配置路径和容器可执行文件路径；新配置优先。
- 保留既有插件协议、数据库迁移、存储和稳定身份标识，避免改名使已有状态失效。
- 为旧版更新器提供兼容命名的安装包。
