# v1.1.3（RC1 候选版）

## 更新内容

- 同步更新 sub2api 0.2.8。
- 恢复按 GPT 模型打票，使用指纹校验票据；支持复用「IP 设置」代理池、自定义失败重试间隔和可选的定时刷新。
- 完善打票成功与失败流水，新增票据失效流水及账号界面展示；两类流水均只保留最近 90 天。
- 为 GPT 账号增加降智检测，可选择多个模型，串行通过正式请求链路测试并正常计费。
- 为 OpenAI 账号增加请求时区设置，默认新加坡且不提供中国大陆及港澳台时区；统一已有的 `Accept-Language` 为英文，并在 Debug 级别记录时区处理结果。

## 注意

- 票据失效流水包含明文票据与 Cookie；请同时核对数据库备份的保留期限。
- 这是候选版本。真实模型效果、生产数据库迁移和生产部署尚未验证；发布前的本地测试结果以实际执行记录为准。
