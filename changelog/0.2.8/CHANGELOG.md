# v0.2.8

## 新增功能

- 新增 Codex 票据功能：自动打票、票据保存与自动刷新，请求时注入有效票据。
- 新增网关票据总开关和独立打票代理配置，并在账号中展示各模型票据状态及剩余有效时间。
- 新增无有效票据时的请求控制：全局默认禁止无票请求，可在网关设置中调整；账号可选择跟随全局、允许无票或禁止无票。有有效票据时优先使用，允许无票的账号仍继续自动打票。
- 新增账号测试自定义提示词，文本测试支持手动输入，留空沿用默认测试提示词。
- 新增账号测试完整上游响应头展示，按响应顺序保留状态码及同名 header 的全部值，涵盖失败、重试、协议回退、轮询与 WebSocket 握手，支持复制。
